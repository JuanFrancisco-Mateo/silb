  • Menús toscos → 3 secciones: Dictar / Historial / Ajustes. Ajustes con 4 grupos colapsables: Audio, Modelo, Corrección IA, Apariencia. Todo lo demás a Avanzado.
  • Primer uso en 30s: solo mic + modelo tiny + botón Dictar. La corrección IA se ofrece después, nunca bloquea.
  • Seguridad demencial: 0 API keys en código/config. Solo endpoint local http://127.0.0.1:8081, sin cloud por defecto, sin telemetría. Limpiar placeholders del historial antes del repo público.
  • LLM opcional: toggle apagado por defecto, perfil ligero small-Q4 por defecto para VRAM baja, aviso si no hay servidor y botón “instalar modelo local”.
